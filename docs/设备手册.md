# DATA RESCUE / 设备手册

## 第一单元：LZ77 长度—距离复制

输出缓冲区已经存有一些字节。复制指令包含 distance（向后距离）和 length（需要复制的字节数）。

重要：复制进行时，新写入的字节可以立即成为后续复制的来源。请不要假设来源区不会变化。

- A01：前缀 HELLO，距离 5，长度 3。目标 HELLOHEL。
- B02：前缀 ABC，距离 3，长度 6。目标 ABCABCABC。
- C03：前缀 X，距离 1，长度 7。目标 XXXXXXXX。
- D04：前缀 NODE-，距离 5，长度 10。目标 NODE-NODE-NODE-。

系统安全约束：distance 不能为 0，不能超过已输出长度；若剩余容量不足，必须拒绝写入，不能破坏缓冲区。

资料：RFC 1951（Deflate），https://www.rfc-editor.org/rfc/rfc1951

## 注意：执行跟踪的定义

游戏的 STEP 1..N 来自一次次真正的 C 函数调用。
每次都先恢复原始前缀，然后分别以 length=1、2、3…N 运行。
它展示“前缀长度探针”结果；不是对一次 C 函数调用逐条指令进行调试。
若你写的算法在不同 length 参数下行为不同，STEP 是这些独立调用的结果。
最后的 CASE 结果才是要求完整 length 时的真实测试结果。
